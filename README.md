# Python de Cero a Experto

## Descripción

Este repositorio contiene ejercicios, scripts y proyectos desarrollados durante el curso **Python de Cero a Experto**. Su propósito es documentar el aprendizaje progresivo del lenguaje Python, desde los fundamentos de programación hasta conceptos de programación orientada a objetos, interfaces gráficas y desarrollo de aplicaciones sencillas.

Los archivos están organizados mediante una numeración que facilita el seguimiento de los ejercicios y la consulta de los temas estudiados.

## Objetivo del repositorio

Desarrollar y consolidar habilidades de programación mediante la implementación de ejercicios prácticos que permitan comprender los fundamentos de Python, resolver problemas y construir aplicaciones utilizando diferentes estructuras y herramientas del lenguaje.

## Contenido del repositorio

### 1. Fundamentos de programación

Ejercicios introductorios para comprender la sintaxis de Python, el manejo de variables, los tipos de datos y las estructuras básicas de control.

Entre los ejercicios se encuentran:

- Restaurante y monedas.
- Registro y validación de edades.
- Ventas diarias y análisis de ventas.
- Validación de contraseñas.
- Juego de piedra, papel o tijera.
- Uso de la biblioteca Colorama.

### 2. Estructuras de datos

Ejercicios enfocados en almacenar, organizar, consultar y modificar información mediante las estructuras de datos integradas de Python.

Temas abordados:

- Listas y operaciones con listas.
- Recorrido e iteración de elementos.
- Comprensión de listas (*List Comprehensions*).
- Tuplas.
- Diccionarios y acceso a sus elementos.
- Iteración sobre diccionarios.
- Conjuntos.
- Eliminación de elementos duplicados.
- Gestión de listas de invitados.

### 3. Funciones y modularidad

Implementaciones orientadas a organizar el código en bloques reutilizables y comprender el funcionamiento de las funciones.

Temas abordados:

- Definición y llamada de funciones.
- Argumentos y parámetros.
- Ámbito de las variables.
- Funciones recursivas.
- Reutilización de código.
- Organización de la lógica de programación.

### 4. Resolución de problemas mediante Python

Ejercicios prácticos que aplican los conceptos de programación para resolver situaciones concretas.

Algunos ejemplos son:

- Simulación de un cajero automático.
- Generación de reportes de edades.
- Análisis de ventas.
- Validación de información.
- Generación de códigos QR.

### 5. Programación orientada a objetos

Ejercicios dedicados al paradigma de programación orientada a objetos (*Object-Oriented Programming, OOP*), que permite estructurar programas mediante clases y objetos.

Temas abordados:

- Creación de clases y objetos.
- Métodos y atributos.
- Constructores y destructores.
- Herencia.
- Polimorfismo.
- Abstracción.
- Encapsulamiento.
- Gestión de empleados.
- Desarrollo de una biblioteca mediante POO.

### 6. Desarrollo de aplicaciones

Proyectos introductorios orientados a construir aplicaciones interactivas y utilizar herramientas adicionales del ecosistema Python.

Proyectos incluidos:

- Chatbot.
- Interfaces gráficas con Tkinter.
- Creación de formularios.
- Aplicación de lista de tareas.

### 7. Manejo de archivos y datos

El repositorio incluye archivos CSV que sirven como recursos para ejercicios relacionados con el manejo de información.

- `datos.csv`: archivo de datos para prácticas de lectura y procesamiento.
- `ventas.csv`: archivo relacionado con información de ventas.

Estos archivos pueden utilizarse para practicar la lectura, consulta y manipulación de datos desde Python, según la implementación de cada ejercicio.

## Herramientas y tecnologías

- **Python:** lenguaje principal de programación.
- **Colorama:** biblioteca para personalizar la salida de texto en la terminal.
- **Tkinter:** biblioteca para desarrollar interfaces gráficas.
- **CSV:** formato de archivo utilizado para almacenar datos tabulares.
- **Git y GitHub:** control de versiones y organización del código fuente.

## Competencias desarrolladas

- Fundamentos de programación.
- Uso de variables, operadores y estructuras de control.
- Manipulación de listas, tuplas, diccionarios y conjuntos.
- Diseño e implementación de funciones.
- Resolución de problemas mediante algoritmos.
- Programación orientada a objetos.
- Manejo de archivos y datos tabulares.
- Desarrollo de interfaces gráficas sencillas.
- Construcción de aplicaciones prácticas con Python.

## Organización del repositorio

Los scripts están numerados para facilitar su identificación y seguir una progresión temática desde los conceptos básicos hasta proyectos de mayor complejidad.

La estructura general del repositorio es la siguiente:

```text
Python_Cero_a_Experto/
├── 1.001 Restaurante.py
├── 1.002 Monedas.py
├── 1.003 Ventas diarias.py
├── ...
├── 1.039 Lista de tareas.py
├── datos.csv
├── ventas.csv
└── README.md
```

## Cómo utilizar este repositorio

1. Clona o descarga el repositorio.
2. Instala Python en tu equipo si aún no lo tienes.
3. Abre los archivos `.py` en tu editor de código preferido.
4. Ejecuta los ejercicios individualmente.
5. Consulta los archivos CSV cuando sean necesarios para ejecutar algún script.

Para ejecutar un archivo desde la terminal:

```bash
python "1.001 Restaurante.py"
```

Es posible que algunos ejercicios requieran instalar bibliotecas adicionales, como Colorama, o utilizar archivos de datos incluidos en el repositorio.
